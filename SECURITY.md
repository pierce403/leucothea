# Security policy

## Reporting a vulnerability

Please **do not** file public issues for security vulnerabilities.

Use GitHub’s “Report a vulnerability” feature (Security Advisories) for this repository if available. If it isn’t available, open a minimal, non-sensitive issue asking for a private reporting channel.

## Scope

The dashboard is intended to help analyze *potential* attack surface changes from git history and configuration. Treat all generated signals as heuristic and verify findings in source and runtime configuration.
